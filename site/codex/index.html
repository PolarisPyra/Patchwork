A desktop app for Codex

Patchwork runs the codex CLI you are already signed in to, on Linux, Windows and macOS, beside your other agents.

Codex, with a window around it

  • Your own sign-in

    Patchwork starts the codex CLI with the login it already has, so your ChatGPT plan works as it does in the terminal.

  • Approve in the chat

    Commands and file changes that need approval show in the chat with Accept and Decline.

  • Steer mid-turn

    Send a message while Codex is working and it reaches the running turn.

  • Goals

    Set a goal with /goal and Codex starts its next turn itself until the goal is met. Stop pauses it.

  • Plans and reasoning

    Codex's plan shows as a checklist beside the chat, and its reasoning summaries show as it works.

  • Plan limits

    The Usage panel shows your Codex rate limits. They are read from files on your machine, and nothing is fetched.

Get started

  1. 1 Install Codex. Install the codex CLI and sign in, if you have not already.
  2. 2 Open Patchwork. It finds the CLI and its login on its own.
  3. 3 Import your sessions. Past Codex sessions come in with their titles, so you can carry on in any of them.

Questions

Is there a Codex GUI for Linux?

Yes. Patchwork is a desktop app for the Codex CLI that ships as an AppImage for x86-64 Linux, as well as for Windows and Apple silicon Macs.

Does Patchwork need an OpenAI API key?

No. It runs the codex CLI with the sign-in it already has.

Can I use Codex and Claude Code in the same app?

Yes. Each task picks its own agent, so Codex, Claude Code, Antigravity and OpenCode tasks sit in the same sidebar.

How do the permission modes map to Codex?

Supervised runs Codex read-only and asks first, Auto-accept edits and Auto let it write in the project, and Full access turns the sandbox off.
