An agentic development environment

An editor is built around the file you are typing in. Patchwork is built around the agents doing the work: what each one is doing, what it changed, and what it may do without asking.

What makes it an ADE

  • Every agent, one window

    Claude Code, Codex, Antigravity, OpenCode and API models share the same chat, plan and code views.

  • An orchestrator

    One page sends each request to the right project and agent, and shows every running task as a card.

  • Supervision

    Four access modes for each task, rules for which commands may run, and approvals in the chat.

  • Extensions for every agent

    Skills, MCP servers and hooks are set up once and work with each agent.

  • Automation

    Goals keep an agent working until they are met, and scheduled tasks start on their own.

  • Native and private

    A native app written in Rust, with no account, no proxy and no telemetry.

Questions

What is an agentic development environment?

An ADE is a workspace for directing coding agents, where an IDE is a workspace for writing code by hand. It shows what each agent is doing, lets you approve or steer it, and keeps its changes reviewable.

How is an ADE different from an AI code editor?

An AI editor adds an agent to an editor. An ADE starts from the agents: several can run at once, each on its own task, and the editor is one view among several.

Which agents does Patchwork run?

Claude Code, Codex, Antigravity and OpenCode, through each CLI's own sign-in, and any OpenAI-compatible API through its built-in agent.

Which systems does it run on?

Linux (x86-64 AppImage), Windows (x64) and macOS on Apple silicon.
