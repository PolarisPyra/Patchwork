One page for every running task

  • Say where it goes

    A request starts a new task in the project you picked, or goes to the project or chat you pin with @.

  • Several projects at once

    One request can be split across several projects, and each gets its own task.

  • Any agent, any model

    Pick the agent, model and effort under the request box: Claude Code, Codex, Antigravity, OpenCode or an API model.

  • A card per task

    Each task shows as a card with its status. Click one to read its chat, and reply from the request box.

  • Tasks that do not collide

    Start a task in a git worktree and it works on its own branch, beside the others.

  • On a schedule

    A scheduled task starts in any project at the time you set.

Get started

  1. 1 Open the Orchestrator. It is the first page Patchwork shows, and Ctrl+1 brings it up from anywhere.
  2. 2 Write a request. Name the project, or pin one with @. Attach files or pictures if it needs them.
  3. 3 Watch the cards. Each task reports on its card, and asks there when it needs you.

Questions

What is an agent orchestrator?

A tool that hands work to several coding agents and tracks it in one place. In Patchwork that is the Orchestrator page: you write requests, it starts the tasks, and each one reports on a card.

Can it run Claude Code and Codex at the same time?

Yes. Each task has its own agent, so a Claude Code task and a Codex task can run side by side, in the same project or in different ones.

How do parallel tasks avoid each other's changes?

Start a task in a git worktree. It gets its own branch and folder, so two tasks in one repository never touch the same files on disk.

Is it free?

Yes. Patchwork is free and MIT licensed. You pay only for the agent plans or API usage you already have.
