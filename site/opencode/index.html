A desktop app for OpenCode

Patchwork runs the opencode CLI on Linux, Windows and macOS, beside your other agents, with every model OpenCode can reach.

Download Patchwork
  • Free and MIT licensed
  • No account
  • No telemetry
  • Linux, Windows and macOS

OpenCode, with a window around it

  • Every OpenCode model

    The model menu lists what opencode models reports, the free ones included. Those need no account.

  • Approve in the chat

    With OpenCode 2, permission requests and questions show in the chat.

  • Steer mid-turn

    With OpenCode 2, a message sent while it is working is delivered to the running turn.

  • Local only

    Each turn starts a private OpenCode server on your own machine with a generated password, and stops it when the turn ends.

  • Your old sessions

    Sessions are imported from OpenCode's own database.

  • Rules for commands

    Allow, ask or deny rules decide each shell command, edit and web fetch as it happens.

Get started

  1. 1 Install OpenCode. Install the opencode CLI. Add providers with opencode auth login, or use its free models.
  2. 2 Open Patchwork. It finds the CLI on its own.
  3. 3 Start a task. Pick OpenCode and a model, and say what you want done.

Questions

Is there a GUI for OpenCode?

Yes. Patchwork is a desktop app that runs the opencode CLI, for x86-64 Linux, Windows and Apple silicon Macs.

Do I need an account?

No. OpenCode's free models need none, and Patchwork has no account of its own.

Which OpenCode versions work?

Both 1.x and 2.x. Approvals, questions and steering in the chat need 2.x.

Does /goal work with OpenCode?

No. OpenCode has no slash commands in Patchwork, /goal included.
