A desktop app for the Antigravity CLI

Patchwork runs Google's Antigravity CLI on Linux, Windows and macOS, beside your other agents, and can install the CLI for you.

Antigravity, with a window around it

  • Installed for you

    No CLI yet? Settings can download Google's installer and keep the CLI in Patchwork's own folder.

  • Your Gemini CLI chats

    Chats saved by the earlier Gemini CLI are imported with their projects.

  • Four access modes

    Supervised, Auto-accept edits, Auto and Full access, set for each task.

  • Goals

    Set a goal with /goal and Antigravity works until it has checked that the goal is met.

  • Rules for commands

    Allow, ask or deny rules are checked before every tool call Antigravity makes.

  • Usage

    The Usage panel shows what Antigravity's own /usage command reports.

Get started

  1. 1 Get the CLI. Install it from Settings, or use the one already on your system, and sign in.
  2. 2 Add a project. Point Patchwork at a folder of your code.
  3. 3 Start a task. Pick Antigravity in the agent menu and say what you want done.

Questions

Is there an Antigravity GUI for Linux?

Yes. Patchwork runs the Antigravity CLI in a desktop app that ships as an AppImage for x86-64 Linux, as well as for Windows and Apple silicon Macs.

Can Antigravity ask for approval in the chat?

Not yet. The CLI cannot ask questions in the mode Patchwork runs it in, so in Supervised mode it skips actions that would need approval.

Can I steer Antigravity mid-turn?

No. A message sent while it is working waits for the next turn.

Does it replace the Gemini CLI?

Antigravity is Google's newer CLI. Patchwork imports the chats the Gemini CLI saved, so you keep that history.
